## Features

- **Craft Agents has a new home: [thecraftagents.com](https://thecraftagents.com)** — the app, downloads, auto-updates, shared session links, and documentation now live on the new domain. Updating to this version switches your app to the new update feed automatically; existing share links and sign-in flows keep working during the transition
- **Documentation rebuilt as a fast static site** — the docs at [thecraftagents.com/docs](https://thecraftagents.com/docs) are now a fully static site with instant search, same content and URLs as before

## Improvements

- Agents now reference the product documentation via the public docs site instead of a built-in documentation source — one less background connection per session
