# Version 0.11.6

## Improvements

- **GitHub Copilot GPT-5.6 models** — GitHub Copilot connections now show GPT-5.6 Luna, Terra, and Sol when those models are available to the account.
- **Native iOS workspace redesign** — Refined server onboarding, added searchable and filterable session rows, introduced document-style assistant responses and richer tool activity cards, surfaced model and permission controls in the composer, improved approval safety, and made the iPad session sidebar visible by default.

## Bug Fixes

- **Packaged Electron renderer** — The desktop UI now loads without relying on Node globals, with browser-safe runtime shims for renderer dependencies. [#62](https://github.com/agisota/craft-agents-oss/pull/62)
- **Stable mind-map identity** — Mind-map content hashes remain deterministic in packaged renderer builds, including multi-block and UTF-8 input. [#63](https://github.com/agisota/craft-agents-oss/pull/63)
- **macOS signing discovery** — Local unsigned builds remain explicit while complete notarization credentials can enable signing identity discovery. [#63](https://github.com/agisota/craft-agents-oss/pull/63)
- **Rox Connect onboarding** — The Rox Connect flow now renders locally in the Electron renderer.
- **OpenAI-compatible streams preserve chunks with empty tool-call arrays** — Custom endpoints that include `tool_calls: []` on ordinary content and terminal chunks no longer lose those chunks in the network interceptor, preventing valid responses from failing with `Stream ended without finish_reason`. Fixes [#995](https://github.com/craft-ai-agents/craft-agents-oss/issues/995).
- **Reliable iOS session loading** — Long conversations now load without hitting Foundation's 1 MB WebSocket limit, session requests wait for active reconnects, transient failures retry automatically, and manual reconnects replace stale session clients without losing unsent drafts.
- **Chinese IME first-character input** — Native `input` events that arrive before `compositionstart` no longer trigger English auto-capitalisation and corrupt the composition session.
- **Visible IME composition text** — Placeholder hints no longer overlay or hide preedit text while IME composition is active.
- **New sessions respect excluded filters** — Creating a session while status, label, or project exclusions are active ignores those exclusions and uses workspace defaults unless exactly one included filter is selected. [#970](https://github.com/craft-ai-agents/craft-agents-oss/issues/970) · `6a3ba29`
